# Emoji catalog

`emoji_catalog.json` contains the base emoji, category order, and English search
terms from the adjacent iOS app's `AksharaKeyboard/EmojiSearchIndex.json`.
Skin-tone variants are omitted because the keyboard applies the user's preferred
tone at display time. The Android build bundles this data and does not require iOS.
